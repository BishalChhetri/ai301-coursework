A control-scenario claim is proven by the diff's own logic, without a separate transcript or test, when the control's stated input would not execute the diff's changed lines — trace the specific input through the diff: if the diff adds a new guarded branch (an early return or conditional) and the control's input does not satisfy that guard's condition, execution falls through to the pre-existing, unmodified code, and the control is proven by that fact alone; this reasoning applies per input, not per file or per function — a diff can modify one branch of a function while leaving another branch's lines completely unexecuted-by-the-change for a given input, and that is enough. ## Verdict rule

Accept (ready to submit) only if all required checks pass. A grade of `unclear` (`?`) on any check counts as fail. No check is `preferred` in this rubric — a PR that is honest about one shortfall but silently drifts on another is not ready to submit.
